## 1. Газовая смесь (нужно для всех типов)

**Массовые доли из мольных:**
$$Y_i = \frac{x_i M_i}{\sum_j x_j M_j}, \qquad M_{mix} = \sum_j x_j M_j$$

**Парциальное давление кислорода:** $p_{O_2} = x_{O_2}\,P$

**Плотность (идеальный газ):** $\rho_g = \dfrac{P\,M_{mix}}{R\,T}$, $R = 8.314$ Дж/(моль·К)

**Теплоёмкость смеси (массовая):** $c_{p,mix} = \sum_i Y_i\,c_{p,i}(T)$

**Вязкость смеси — правило Уилке:**
$$\mu_{mix} = \sum_i \frac{x_i \mu_i}{\sum_j x_j \Phi_{ij}}, \quad
\Phi_{ij} = \frac{\left[1 + (\mu_i/\mu_j)^{1/2}(M_j/M_i)^{1/4}\right]^2}{\sqrt{8\,(1 + M_i/M_j)}}$$

**Теплопроводность смеси — Мейсон–Саксена:** та же форма, что у Уилке, с $\lambda_i$ вместо $\mu_i$
(упрощённый вариант: $\lambda_{mix} = \tfrac12\left[\sum x_i\lambda_i + \left(\sum x_i/\lambda_i\right)^{-1}\right]$).
⚠️ Для смесей с гелием простое правило завышает $\lambda$ — использовать Мейсон–Саксена.

**Температура оценки свойств** (правило «1/2» или «1/3»):
$$\bar T = T_s + \tfrac12 (T_f - T_s) \quad\text{или}\quad \bar T = T_s + \tfrac13 (T_\infty - T_s)$$
Выбор — решение Руслана (ADR).

**Числа подобия:**
$$Pr = \frac{\mu c_p}{\lambda}, \quad Le = \frac{\alpha}{D} = \frac{\lambda}{\rho c_p D}, \quad
Gr = \frac{g\,\beta\,\Delta T\,L^3}{\nu^2},\ \beta \approx \frac1{T_\infty}, \quad
Re = \frac{\rho V L}{\mu}$$

**Перевод единиц:** 1 атм = 760 мм рт. ст. = 101.325 кПа = 14.696 psia; 1 psia = 6.895 кПа.

Источники: Turns, *An Introduction to Combustion*, 3rd ed., гл. 3 и прил.; Poling, Prausnitz, O'Connell, *The Properties of Gases and Liquids*, 5th ed. (Уилке, Мейсон–Саксена).

## 2. Горение капли — квазистационарная теория (FLEX, FLEX-2, CFI)

**Закон d²:**
$$d^2(t) = d_0^2 - K\,t, \qquad t_b = \frac{d_0^2}{K}$$

**Константа скорости горения:**
$$K = \frac{8\,\lambda_g}{\rho_l\,c_{p,g}}\,\ln(1 + B)$$

**Массовая скорость горения:**
$$\dot m_F = \frac{4\pi\,\lambda_g\,r_s}{c_{p,g}}\,\ln(1 + B)$$

**Число переноса Сполдинга для горения:**
$$B = \frac{Y_{O,\infty}\,Q/\nu_s + c_{p,g}\,(T_\infty - T_s)}{L_{eff}}, \qquad
L_{eff} = h_{fg} + c_{p,l}\,(T_s - T_{l,0})$$
- $Q$ — низшая теплота сгорания, Дж/кг топлива;
- $\nu_s$ — стехиометрическая масса O₂ на кг топлива (метанол: 48/32.04 = 1.50; н-гептан: 352/100.2 = 3.51);
- $T_s \approx T_{boil}$ при давлении опыта (зависит от P — уравнение Клаузиуса–Клапейрона).

**Стехиометрическая доля смешения:**
$$Z_{st} = \frac{Y_{O,\infty}}{Y_{O,\infty} + \nu_s}$$

**Температура пламени (Бурке–Шуман, бесконечно быстрая реакция):**
$$T_f = T_\infty + Z_{st}\left[(T_s - T_\infty) + \frac{Q - L_{eff}}{c_{p,g}}\right]$$

**Положение пламени (отношение радиусов):**
$$\frac{r_f}{r_s} = \frac{\ln(1 + B)}{\ln\!\left(1 + Y_{O,\infty}/\nu_s\right)}$$
В эксперименте пламя ближе к капле из-за накопления паров топлива — это одна из ошибок теории, которую учит ML.

**Влияние давления на температуру кипения (Клаузиус–Клапейрон):**
$$\ln\frac{P}{P_{ref}} = -\frac{h_{fg} M}{R}\left(\frac1{T_s} - \frac1{T_{boil,ref}}\right)$$

Источники: Turns гл. 10; Law, *Combustion Physics* (2006), гл. 6; Williams, *Combustion Theory*.

## 3. Затухание пламени капли

**Радиационные потери (оптически тонкое приближение):**
$$\dot Q_{rad} = 4\sigma\,a_P\,(T_f^4 - T_\infty^4)\,V_f, \qquad
V_f \approx \frac{\pi}{6}\,(d_f^3 - d^3)$$
$$a_P = P\sum_i x_i\,a_{P,i}(T) \quad (\text{CO}_2,\ \text{H}_2\text{O},\ \text{сажа})$$
$\sigma = 5.670\cdot10^{-8}$ Вт/(м²·К⁴).

**Тепловыделение:** $\dot Q_{comb} = \dot m_F\,Q$

**Доля радиационных потерь:**
$$\chi_{rad} = \frac{\dot Q_{rad}}{\dot Q_{comb}} \;\propto\; \frac{d_f^3}{d} \propto d^2$$
→ **большие капли гаснут из-за излучения** (радиационное затухание), критическое $\chi_{rad}$ подбирается по данным.

**Диффузионное затухание (малые капли) — число Дамкёлера:**
$$Da = \frac{\tau_{flow}}{\tau_{chem}}, \quad \tau_{flow} \sim \frac{r_f^2}{\alpha_g}, \quad
\tau_{chem} \sim \frac{1}{A\,\rho\,Y_O\,\exp(-E_a/RT_f)}$$
Пламя гаснет при $Da < Da_{crit}$ → **малые капли гаснут из-за короткого времени пребывания**.

**Итог для модели:** признаки $\chi_{rad}$, $Da$, $T_f$; исход «самозатухание / догорание»; доля несгоревшего топлива $(d_{ext}/d_0)^3$.

**Холодные пламена (cool flames, открытие FLEX):** после радиационного затухания горячего пламени н-алканы продолжают гореть в режиме низкотемпературного окисления (~600–800 К, по данным NASA — сверить по отчётам FLEX). Моделью d² не описываются — только как факт из литературы NASA.

Источники: Law гл. 6, 10; Dietrich et al., *Microgravity Sci. Technol.* (2014), doi:10.1007/s12217-014-9372-2; NASA/TP-2015-216046.

## 4. Распространение пламени по твёрдому материалу (BASS, BASS-II, SoFIE, Saffire)

**Встречный поток, термически тонкий образец (де Рис):**
$$V_f = \frac{\sqrt2\,\lambda_g\,(T_f - T_v)}{\rho_s\,c_s\,\tau\,(T_v - T_\infty)}$$
$\tau$ — полутолщина образца, $T_v$ — температура пиролиза.

**Встречный поток, термически толстый образец (де Рис):**
$$V_f = V_g\,\frac{\lambda_g\,\rho_g\,c_g\,(T_f - T_v)^2}{\lambda_s\,\rho_s\,c_s\,(T_v - T_\infty)^2}$$

**Критерий тонкий/толстый:** сравнить $\tau$ с толщиной прогретого слоя $\delta_s \sim \alpha_s / V_f$.

**Пределы горючести в невесомости (U-образная карта «скорость потока — O₂»):**
- при малой скорости потока — гашение излучением (нет конвекции, которая подаёт окислитель);
- при большой — срыв: $Da = \tau_{res}/\tau_{chem} < Da_{crit}$, $\tau_{res} \sim \alpha_g/V_r^2$, $V_r = V_g + V_f$.
- **Предельная концентрация кислорода (LOC/MOC):** O₂, при котором $V_f \to 0$. Определяется по данным (экстраполяция зависимости $V_f(x_{O_2})$ к нулю).

Источники: de Ris, *Proc. Combust. Inst.* 12 (1969); Fernandez-Pello, *Combust. Sci. Technol.* (1984); T'ien et al. — обзоры по горению твёрдых тел в микрогравитации; отчёты NASA по BASS/Saffire (NTRS).

## 5. Газовые струйные пламена (ACME, LSP, Flame Design)

**Длина ламинарного диффузионного пламени, круглое сопло (Roper):**
$$L_f = \frac{Q_F\,(T_\infty/T_F)}{4\pi\,D_\infty\,\ln(1 + 1/S)}\left(\frac{T_\infty}{T_f}\right)^{0.67}$$
$Q_F$ — объёмный расход топлива, $S$ — стехиометрическое мольное отношение «окружающая смесь/топливо», $D_\infty$ — коэффициент диффузии.
По теории Roper длина круглой струи почти не зависит от гравитации; в невесомости пламя **шире** и дольше живёт сажа.

**Корреляция для расчёта (Turns, гл. 9):** $L_f \approx 1330\,\dfrac{Q_F\,(T_\infty/T_F)}{\ln(1 + 1/S)}$ (СИ) — сверить номер уравнения.

Источники: Roper, *Combust. Flame* 29 (1977); Turns гл. 9; отчёты NASA по ACME (NTRS).

## 6. Земля против МКС (поправка на гравитацию)

**Естественная конвекция для сферы (Ранц–Маршалл):**
$$Nu = 2 + 0.6\,Gr^{1/4}\,Pr^{1/3}$$
$$\frac{K_{1g}}{K_{0g}} \approx \frac{Nu}{2}, \qquad Gr = \frac{g\,(T_f - T_\infty)\,d^3}{T_\infty\,\nu^2}$$
- в невесомости $g \to 0$ → $Nu = 2$ → чистый закон d²;
- $\nu = \mu/\rho \propto 1/P$ → $Gr \propto P^2$: **на Земле давление влияет на горение сильнее, чем на МКС**.

**Характерная скорость плавучести (для сравнения с вентиляцией МКС):**
$$U_b \sim \sqrt{g\,d\,\frac{T_f - T_\infty}{T_\infty}}$$

Источники: Ranz & Marshall, *Chem. Eng. Prog.* 48 (1952); Law гл. 6 (конвективные поправки).

## 7. Пожар в кабине (контекст Apollo 1, «Мир»; данные Saffire, если взяты)

**Тепловыделение по расходу кислорода (метод Хаггетта):**
$$\dot Q \approx 13.1\ \text{МДж/кг O}_2 \times \dot m_{O_2,consumed}$$

**Падение O₂ в замкнутом объёме:**
$$\frac{dx_{O_2}}{dt} \approx -\frac{\dot m_F\,\nu_s}{\rho\,V_{cabin}}\cdot\frac{M_{mix}}{M_{O_2}}$$

**Рост CO₂** — по стехиометрии сгорания; **CO** — по измеренным выходам (Saffire/BASS-II), а не по теории (CO убил экипаж Apollo 1 — ресурс R2).

Источник: Huggett, *Fire and Materials* 4 (1980); отчёты NASA по Saffire (NTRS).

## 8. Гибридная модель, валидация, ранжирование

**Калибровка теории (одна константа на топливо/материал):**
$$c_f = \exp\!\left[\frac1n\sum_{i \in f}\left(\ln K_i^{meas} - \ln K_i^{theory}\right)\right]$$

**Остаток, который учит ML:**
$$r = \ln\frac{K^{meas}}{c_f\,K^{theory}}$$

**Гибридный прогноз с интервалом (ГП даёт $\mu_r, \sigma_r$):**
$$\hat K = c_f\,K^{theory}\,e^{\mu_r(\mathbf x)}, \qquad
K_{95\%} \in \left[\hat K e^{-1.96\sigma_r},\ \hat K e^{+1.96\sigma_r}\right]$$

**Классификатор самозатухания (логистическая регрессия):**
$$p = \frac{1}{1 + \exp\left[-(\beta_0 + \sum_k \beta_k z_k)\right]}, \quad z_k = \frac{x_k - \bar x_k}{s_k}$$

**Метрики:**
$$R^2 = 1 - \frac{\sum (y - \hat y)^2}{\sum (y - \bar y)^2}, \quad
MAE = \frac1n\sum|y - \hat y|, \quad
RMSE_{log} = \sqrt{\frac1n\sum(\ln y - \ln\hat y)^2}$$
$$\text{Brier} = \frac1n\sum (p_i - y_i)^2, \qquad AUC = P(p_{pos} > p_{neg})$$

**Ранжирование выводов (вариант по умолчанию, утверждает Руслан):**
$$S = w_{evidence}\cdot\ln(1 + n_{tests})\cdot(0.3 + 0.7\,e), \qquad e \in [0, 1]$$
$w$: NASA data 1.0 · model 0.7 · NASA literature 0.6 · physics theory 0.5 · NASA history 0.5 · NASA spinoff 0.3.
